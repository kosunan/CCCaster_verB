# 国旗エンブレム

24種類の国旗を模した24×12px・24bit非圧縮BMP。各ファイルは288画素・918バイト。
図柄はこの解像度に合わせた簡略表現で、正式な国旗の縦横比や紋章の細部は再現しない。
外部画像は使用せず、`generate.py` のピクセル配置から生成する。

```powershell
python -X utf8 src/src/gui_launcher/assets/emblems/generate.py
```

BMPと `EmblemCatalog.hpp` を再生成する。BMPはGUIのRCDATAへ埋め込み、実行時に外部ファイルを要求しない。
設定画面の「国旗プリセット」から選択すると、GUIと同じフォルダーの `player-emblem.bmp` へ自動保存する。
利用者のBMPも同じ登録条件で検証し、切抜きやリサイズは行わない。

一覧: 日本、アメリカ、イギリス、カナダ、ブラジル、アルゼンチン、フランス、ドイツ、イタリア、スペイン、ポルトガル、オランダ、ベルギー、アイルランド、スウェーデン、ノルウェー、デンマーク、フィンランド、スイス、ポーランド、ウクライナ、オーストリア、中国、韓国。
