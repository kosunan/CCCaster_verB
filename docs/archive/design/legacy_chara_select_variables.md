# 旧来仕様：キャラクターセレクト同期 業務変数設計書

## 1. 概要
旧CCCaster（v3時点）で定義され、新アーキテクチャ（v10）の `core_dll` においてキャラクターセレクト時の同期ズレを防止するために利用されるメモリアドレスや定数、業務変数を定義します。

## 2. 各種定数・メモリアドレス定義 (GameHooks.hpp / memory_map)

### 2.1. ボタン入力ビットマスク変数
ゲームの内部入力データにおいて、特定のボタンが押されているか判定・操作するためのビットフラグです。
- `BUTTON_A` (`0x0010`): Aボタン（弱攻撃など）。キャラセレにおいては決定ボタンとして機能。
- `BUTTON_B` (`0x0020`): Bボタン（中攻撃など）。キャラセレにおいてはキャンセル・戻るボタンとして機能。
- `BUTTON_CONFIRM` (`0x0400`): 純粋なシステム「決定」ボタン。
- `BUTTON_CANCEL` (`0x0800`): 純粋なシステム「キャンセル」ボタン。

### 2.2. キャラクターセレクト状態検知アドレス
各プレイヤーのUIが現在「キャラクターを選択中」か「ムーン等（その他）を選択中」かを識別するためのゲームメモリアドレスです。
- `P1_SELECTOR_MODE_ADDR` (`0x74D8EC`): 1P（左側）のセレクター状態アドレス。
- `P2_SELECTOR_MODE_ADDR` (`0x74D910`): 2P（右側）のセレクター状態アドレス。

### 2.3. セレクターモードの値
上記アドレスに格納される値の定義です。
- `SELECT_CHARA` (`0`): 現在キャラクターを選択している状態を示します。

## 3. 業務変数・クラスプロパティ (InputFilter 等)

### 3.1. `framesInCharaSelect` (uint32_t)
- **概要:** キャラクターセレクト画面（`CC_GAME_MODE_CHARA_SELECT = 20`）に移行してからの経過フレーム数をカウントする一時的な変数です。
- **用途:** 「画面に入ってから150フレーム間は決定ボタンを無効化する」という業務フロールールの条件判定に使用します。状態が変わる（Loadingに行く等）か、ネットプレイがリセットされると `0` に初期化されます。

### 3.2. `rawInput` (uint16_t)
- **概要:** DirectInputやOSのキーボードイベントレイヤーから取得された、加工前の純粋な1フレーム分の入力情報です。

### 3.3. `filteredInput` (uint16_t)
- **概要:** `InputFilter::FilterCharaSelectInput` で業務ルールに従って不要なビットマスクが削除（クリア）された後の入力情報です。この変数が実際にネットワークで送信され、ゲーム関数（`AdvanceFrame`など）のパラメータに渡されます。
