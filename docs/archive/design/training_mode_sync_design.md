# トレーニングモード同期仕様設計

## 1. コンセプト
トレーニングモードでは、通常の対戦同期に加え、プレイヤーのメタ操作（セーブ、ロード、リセット）を両クライアント間で完全に一致させる必要があります。

## 2. 状態同期コマンド (Command Packet)
通常の入力パケットとは別に、信頼性の高い（ACK必須の）コマンドパケットを使用します。

### 2.1 Reset (同期リセット)
1. **Trigger**: どちらかのプレイヤーが「リセット」ボタンを押下。
2. **Action**: 
   - 押下側が `CMD_TRAINING_RESET` パケットを送信。
   - 送信側・受信側ともに、現在の実行フレームを強制的に `0` に設定。
   - ゲームエンジンの状態を初期位置・初期状態へ LoadState する。
   - 完了後、両者の SyncEngine を Playing 状態へ遷移。

### 2.2 Save/Load State (状況保存・復帰)
1. **Save**:
   - `CMD_TRAINING_SAVE` を送信。
   - 現在の `GameState` を、共有される「セーブスロット」に同期して保存。
2. **Load (Restore)**:
   - `CMD_TRAINING_LOAD` を送信。
   - 保存された `GameState` を両クライアントで同時に展開し、その時のフレーム数から再開。

## 3. 同期ズレ防止策
- **Stall during command**: コマンド実行中は、相手の「了解(ACK)」が来るまでゲーム進行を一時停止し、確実に同じフレームから再開することを保証する。
- **Seed Synchronization**: リセット・ロード時に乱数シードも同期し、その後の展開がズレないようにする。
