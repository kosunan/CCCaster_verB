# 01 System Overview (システム全体要件)

## 1. CCCaster_v10 とは
『MELTY BLOOD Actress Again Current Code』(MBAACC) に向けた、完全新規かつオープンソースの通信対戦・ロールバック実装です。旧CCCasterの複雑化した構造を刷新し、AIや新規開発者が参入しやすい「関心の分離」に基づいたモダンなアーキテクチャを採用しています。

## 2. システムのコア価値（Core Value）
1. **インゲーム処理の徹底**: 描画、入力、ロールバックエンジンの処理はすべてゲーム内部のメモリ空間（DLLフック）で行い、IPC等によるオーバーヘッドを排除する。
2. **チューニング容易性**: WASAPIによる高精度タイマーと、状態管理の明確な責任分解により、フレーム単位のエッジケース解析を可能にする。
3. **P2P通信への回帰＋拡張**: 旧世代の仕組みから必要な部分（Hash Connect）を受け継ぐ一方で、中継サーバー（Relay）への拡張性を備えた非同期UDPライブラリ（ASIO）レイヤーを持つ。

## 3. コンポーネント構成と責任境界

### 3.1 Main App (CLI & Launcher)
- **役割**: ユーザーと直接対話するCLIの提供、UDPポートの占有確保、接続先（Peer）とのNAT越え・生存確認（SessionNegotiation）、およびゲーム本体プロセス(MBAA.exe)の起動とDLLインジェクト。
- **制約**: ゲーム空間外のプロセスであるため、ゲームロジックや毎フレームの細かな同期には一切関与しない。

### 3.2 Core DLL (Game Hook & Sync Engine)
- **役割**: ゲーム本体のプロセスに寄生し、DirectXの描画終了や入力API（DirectInput）の呼び出しをフックし、GGPOベースのRollbackEngineを駆動する。
- **制約**: UI描画はImGuiを通じたオーバーレイのみ。ネットワーク通信はバックグラウンドスレッドで独立して行う。

### 3.3 DummyPeer (Testing Tool)
- **役割**: Core DLLの通信プロトコル（主に時間同期や入力送受信）をエミュレートするスタンドアロン・テスト検証ツール。
- **制約**: 本体のゲームロジックを持たないため、ゲーム内メモリとは無関係に「ネットワーク上での振る舞い」のみをテストする。

## 4. 目標とするユーザー体験（UX）
- CCCaster_v10を立ち上げ、わずか数ステップのCLI操作で対戦相手と自動で接続され、ゲームが最速で起動する。
- ラウンド開始時の暗転ドロップや、対戦中のスタッター（カクつき）を極小化する。
- 対戦中の通信状況（Ping/Loss/Jitter等）が、ゲーム内オーバーレイで透過的に確認できる。
