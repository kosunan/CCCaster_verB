# FN1保存・長押し停止とFN2リセット後の自動ロード

2026-09-14。トレーニングの戦闘画面に限り、独立した保存／読込ボタンからFN1・FN2へ操作を統合する。

## 操作仕様

- FN1は押した瞬間を1回保存し、成功した場合だけ、離すまで両キャラを停止する。画面下に `STATE SAVED - RELEASE FN1 TO RESUME` を表示。保存失敗時は以前の保存を保持し、停止は開始しない。
- FN1のゲーム本来の機能は戦闘画面へ渡さない。FN1を離す、FN2を押す、機器切断、F4設定開始で停止を解除する。設定終了後の押しっぱなしは再保存しない。
- FN2は通常のリセット入力を先にゲームへ渡す。保存がある時だけ復元を予約し、その後のイントロ終了、または戦闘時計の初期化を検出して一度だけロードする。FN2の長押しをロード後に再送して連続リセットさせない。
- 保存がない時のFN2はゲーム本来の入力をそのまま渡す。FN2の操作なしに移動して初期位置に戻る、ゲーム内メニューからリセットする等ではロードしない。予約したリセットが完了しなければ10秒で予約を捨てる。
- キャラセレクト等で戦闘を離れたら保存を消去。同じ戦闘内の操作キャラ交代やラウンド番号の変化だけでは破棄しない。実際の復元失敗は無効な保存として通知する。
- FN1とFN2の同時押しはFN2を優先する。メニュー一時停止・F4中の新規保存は受け付けない。ヒットストップ中の保存は引き続き可能。
- F4の割当欄を `FN1 Save_state` / `FN2 Load_state` とし、長押し停止、リセット後の読込、保存なしの通常リセット、キャラセレでの消去を説明。旧TrainingSave/TrainingLoad欄は表示・実行しない。既存INIの値は保全するが、操作は既存FN1/FN2の割当に従う。

## 実装境界

保存・復元・停止の書込みはゲームスレッドのみ。独立入力時計で取得した通常入力を、F4解除待ちのゲートに通してからFN1/FN2へ分岐する。ネット対戦・観戦には適用せず、通信版10、接続コード、製品バージョンは変更しない。

両キャラ停止はゲームの全体停止カウンタ0x562A48を使用。0x423998の1減算後も停止するよう2をセットし、次のPresentで元のカウンタと0x55DF00の停止判定フラグを復元してから状態を評価する。保存スナップショットに人工的な停止値を混入させない。描画・BGM・入力採取・60Hz待機は継続し、戦闘時計自体は長押し中も進む。押下中は通常ゲーム入力をニュートラルにする。

通常pauseの0x55D203を使う試作はゲームのメニューまで表示されたため不採用。全体停止方式の実画面で、メニューを出さず保存の案内を表示することを確認した。

FN2の通常リセット自体が一時停止を1更新挟むため、その停止でロード予約を取り消さない。F4開始時の予約取消は維持する。単体試験にもこの経路を追加した。
