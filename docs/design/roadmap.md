# CCCaster_v10 開発ロードマップ

本ドキュメントは、プロジェクト「CCCaster_v10（完全新規 通信同期ツール）」の全体的な開発および実装の順序を規定するものです。
すべての開発プロセスは、以下の段階的なステップ（1〜4）に基づき一貫性を持って順番に実施されます。

## 1. CLI画面処理 (Phase 1)
コマンドラインUI（CUI）の基盤を構築し、ツールとしての入出力・状態遷移の枠組みを作成する。
* **[済]** プロジェクト初期化
* **[済]** メニュー画面（Host/Client選択等）とステートマシンの実装

## 2. UDP通信の確立 (Phase 2)
ゲームに干渉する前に、まずはツール単体での双方向通信が安定して成立することを実証する。
* **[済]** 冗長化UDPパケットの実装（最新+過去10入力同梱）
* **[済]** 継続的なパケット送受信ループの構築（パケットを途切れず送り続ける状態の維持）
* **[済]** 通信ステータス監視機能の実装とCLI/ログへの出力
  * `Ping` (ミリ秒)
  * `ジッター / Jitter` (揺らぎ幅)
  * `通信頻度 / Packets per sec` (秒間送受信回数)
  * `パケットロス / Packet Loss` (%)

## 3. オフライントレーニングモードのゲーム起動確認 (Phase 3)
オンライン機能へ進む前に、ゲーム（MBAA）のプロセス空間へ入り込み、メモリへの読み書きが正しく機能することを実証する。
* **[済]** ゲームプロセスへのフック（MinHook等のインジェクション）基盤の確立
* **[済]** オフライン環境での実験的インゲーム干渉（例：常時体力MAX化、強制座標セット等の簡易テスト）

## 4. ネット対戦 (Phase 4)
実際の対戦フローに沿って、ロールバックエンジンとゲームフックをオンライン越しに段階的に結合する。
このフェーズは以下のサブステップで進行する。
* **4-1. キャラクターセレクトの同期**
  * キャラセレ画面での互いの入力やカーソルの一致（メニュー状態の同期）。
* **4-2. オフライン(Training)モードの完全同期**
  * オフラインの仮想空間内で、同一のパケットルーター実装を用いて通信とロールバックエンジンの安定稼働を検証する。
* **4-3. InGame UI (ImGui オーバーレイ) の実装**
  * ゲーム空間内（DirectXフック）での、ImGui等を用いた設定値の変更や通信ステータスの前面表示。
* **4-4. ラウンド開始時 同期**
  * 対戦画面への移行時、両プレイヤーの「Ready（ラウンド開始状態）」の厳密な待ち合わせと同期開始シークエンス。
* **4-5. 高精度ロールバック 同期**
  * ロールバックエンジン（最大128Fバッファ）のインゲームでの本稼働。
  * VirtualClock補正による60FPSの維持。
  * **[重要デバッグ要件]**: デバッグ版において、高速再計算（Rollup）にかかる性能・処理時間を何らかの形で画面へ表示し、チューニングの指標とする。

---
> [!IMPORTANT]
> **進行ルール**: それぞれのステップ（項目）が完了するたびに、必ずビルドおよび動作テストを行い、マスター（ユーザー）へ結果を申告してから次のステップへ移行すること。
