# ボタン割当の安全性とトレーニング状態保存

対象: MBAACC Ver.1.07 Rev.1.4.0 / 32bit。2026-09-12。

## 変更内容

- F4を開くと保存済みの入力を一覧表示。P1/P2、デバイス、項目を明示的に選択する。パッドを押して動作確認しただけでは割当を開始しない。
- 1項目変更、基本13項目の連続割当、戻る、現在の値を維持して次へ、任意項目の解除、既定値復元、変更の取消を提供。設定は保存成功までドラフトとして扱う。既定値復元も取消可能。
- 移動4方向とA/B/C/D/E/Startは必須。通常13項目の重複は保存を止め、原因を表示する。未編集の旧設定は無断修正せず、開閉だけではINIを一切書かない。
- 任意の`TrainingSave` / `TrainingLoad`を追加。通常入力との重複・相互重複を許可。同時押下時は読込優先。ゲーム入力のビット列や通信形式へは混在させない。
- instance GUIDで接続個体を追跡。同名複数台の列挙順変更や片方の切断で別個体へ移らない。従来の名前だけのINIは読込互換を維持し、編集保存時は`機器名__GUID.ini`へ分離。USBポート等でGUIDが変わった時は設定から再選択する。
- 任意の追加スティック方向をUIで解除可能にし、隠れた常時アナログ割当を可視化。入力取得失敗時は以前の押下を保持せずニュートラルにする。
- 保存は一時ファイルから置換し、既存ファイルは`.bak`を残す。書込失敗では閉じず、ドラフトと失敗表示を保持。複数ファイル全体の原子的トランザクションではなく、一部保存失敗時は再試行案内を表示する。
- 画面遷移でF4を閉じる際は自動保存せず、未保存ドラフトを次回まで保持。ゲーム入力遮断は解除し、従来のニュートラル待ちを維持する。

## トレーニング状態

オフライントレーニング(appMode=1)の有効な戦闘状態のみ。ゲームスレッド上で既存のGameMemスナップショット経路と浮動小数点環境を保存・復元する。メモリ内1枠で、ディスク保存・リプレイ出力はしない。通常対戦、観戦、CPU対戦、リプレイでは呼び出さない。

押下エッジで1回だけ動作。設定画面中、停止中、画面遷移からの押しっぱなしは抑止し、一度離してから押し直す。画面・ラウンド・操作キャラの世代変更で保存状態を破棄する。保存失敗は以前のスロットを保全。読込失敗時は古いスロットを無効化する。有利不利計測は読込後にリセットする。

トレーニング戦闘中もF4で再設定可能。設定中の有利不利HUDは描かず、デバイス欄との重なりを避ける。保存・読込・未保存通知は4秒維持し、下端中央の小さな1行で表示する。ネット対戦中のHUD、入力時計、締切、ホットプラグ禁止は変更しない。接続再列挙は引き続きキャラ選択だけ。

## 検証

- 32bit Releaseビルド、PE Machine 0x014c、29 CTest成功。`controller_mapping`はReleaseで無効になるassertから常時検査へ変更し、78検査成功。実UIロジック・実INI保存・ImGuiを使い、覗くだけの無変更、重複の保存拒否、個別修正、任意解除、GUID分離、取消、切断中ドラフト保持、再接続、保存失敗、キーボード既定値を確認。状態保存のモード制限、長押し、同時押し、未保存読込、失敗、画面遷移も検査する。
- Computer Useによる640x480実画面確認。検証用`_TEST_CLOSE_MBAACC/MBAACC_1/controller_ui_probe_20260912`を作成し、普段の設定と分離。キーボードS/Dの保存・読込割当、実DirectInput仮想DS4のB0/B1割当をUIから保存。A/Bとの重複を許可し、通常プロファイル経路でキャラ選択とトレーニングへ到達。試験用入力バイパスは使用していない。
- 初回実機では未保存読込→案内、1秒長押し保存→1回、移動→1秒長押し読込→1回と位置復元を確認。F4中に同じボタンを押しても保存・読込ログは増えない。通知帯と有利不利HUDの重なりを見つけて修正した。初回記録は`build_logs/controller_mapping_20260912/ui_training_first.log`。
- 最終版の40秒実ネット対戦（15～25ms / 損失5%）は1320確定F一致、入力・代表状態・保存領域ログの差分/欠落0。ホスト8回/クライアント3回のRB、最大深度1、失敗0。ログと比較結果は`build_logs/controller_mapping_20260912/netplay/`。瞬間周期精度の合格を意味しない。
- 最終実画面で通常A/BのB0重複は赤字になり、F4で閉じようとしても拒否され、REVERTで保存済みB1に戻ることを確認。トレーニング保存WT5305へ、移動後WT5439から復元。保存・読込を各1秒保持しても各1回。下端中央の小通知と設定中の有利不利HUD非表示を確認。最終ログは`ui_training_final.log`（初回ログも含む、最終はbeforeWT/afterWT表記）。
- `build_logs/controller_mapping_20260912/verification.json`に検証結果、SHA256、56 INI不変を保存。通常2窓へ同一EXE/DLLを差し替え済み。試験で起動したゲームと仮想パッドは終了した。既存ゲーム・物理機器設定を変更していない。

## 未確認・制限

物理機種別の全入力、同型物理2台の挿抜、全キャラの特殊状態・人形・長時間の保存復元、別PC/DPI/全画面は未確認。状態保存は既存ロールバック保存表を使うため、ゲーム全メモリの完全な復元や再起動後の復元を保証しない。停止中はボタンを離し、再開後に押し直す必要がある。対戦HUDは維持し、設定とトレーニング通知に変更を絞った。
