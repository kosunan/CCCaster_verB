# テスト用CLIを維持し対戦募集とコード参加のGUIを追加する

この文書は追加当日の記録。2026-09-12にランク／マッチングを凍結し、[アーケード調のGUI初案と観戦復元方針](2026-09-12_arcade_gui_and_spectating.md)へ更新した。現行の色・メニュー構成は新しい記録を参照する。

## 起動と画面

- ユーザー向け: `build/bin/CCCaster_v10_GUI.exe`。濃紺とシアンの英語画面、常設の「日本語 / English」言語切替ボタン、募集／参加の明示的な切替、大きな開始ボタン、状態欄、操作ガイド。
- テスト向け: 従来の `CCCaster_v10.exe --headless ...`。テストスクリプト・CLI引数は変更しない。
- 実ゲーム環境では `MBAA.exe` の隣の `cccaster/` にGUI・`libcccaster_hook.dll`・`cccaster_v10.ini` を置く。build/binだけでも画面は開くが、ゲーム未配置なら開始時に案内する。
- GUIはオンライン対戦とオフライントレーニングに対応。観戦はGUIに追加していない。コントローラ設定は従来のゲーム内F4。

## 実装

`src/gui_launcher` のImGui/Win32/D3D9画面から、同じGUI EXEの内部 `--worker` をコンソールなしで起動する。GUIとworkerのビルドは既存CLIのコントローラ・接続処理を共有する。画面スレッドでは接続やゲーム終了を待たない。

GUI workerは引数による自動接続を使うが、IPCのheadlessModeはfalseにする。ゲーム終了や例外時はworkerを終了し、対話メニューやキー待ちへ入らない。通常CLIの動作は変更しない。

キャンセルはGUIプロセスごとの名前付きイベントで通知する。接続処理の開始前・待受ループ・ゲーム起動直前で確認する。ゲーム起動後のキャンセルはゲームを強制終了せず、GUIを閉じても実行中のゲームを維持する。既存の起動失敗時処理は共有ランチャーに従う。

設定はEXE隣のINIを読み取り、D/Rの範囲を開始前に確認する。設定ファイルやコントローラ設定の上書きは行わない。ログは一時フォルダーの `CCCaster_GUI_<GUI PID>.log` に保存する。画面は直近64KiBを読み、表示は24KiBに制限する。状態は既存ログの文言から判断するため、今後その文言を変える場合はGUIの解析も更新する。

## 確認済み

- MinGW32 ReleaseのGUI/CLIビルド成功。EXEは双方Machine 0x014c。GUI Subsystem 2、CLI Subsystem 3。
- `ipc_isolation`、`settings_commands` の2テスト成功。
- GUI workerへ不正コードを渡した際、キー待ちせず終了。開始前にキャンセルイベントを設定した場合も終了。正常対戦の代用ではない。
- Computer Useで募集・参加・操作ガイドの画面切替、コード未入力時の参加ボタン無効化を確認。状態欄の余分なスクロールと未収録記号を修正。既定は英語。「日本語 / English」ボタンでメイン画面・操作ボタン・状態・入力エラー・操作ガイドを即時に切り替える。言語変更で入力値や接続状態は初期化しない。診断ログ本文は調査用の原文、製品名・ファイル名・接続コードは保持する。言語設定は今回保存せず、起動時は英語。
- ビルド・試験ログ: `build_logs/gui_20260911/build.log`、`tests.log`、`worker_tests.log`、`invalid_hash.log`、`cancelled.log`。

## 未確認

GUI経由の正常接続・コードコピー・待受中キャンセル・手操作対戦・終了後の再接続、複数モニター間のDPI変更は未確認。今回ゲームDLLの入力・同期・タイミング・フック実装は変更していない。GUI経由の実対戦や入力精度を確認済みとは扱わない。

## 言語切替の確認

32bit GUIの再ビルド成功（`build_logs/gui_20260911/build_language_toggle.log`）。Computer Useで英語既定→日本語→英語の切替を実画面で確認。見出し、ナビゲーション、状態文、募集ボタン、ポート、D/R説明が切り替わり、ポート7500を保持。診断ログ本文は原文を保持する。表示変更のみのため実対戦試験は追加していない。

## トレーニングモードの追加

- `TRAINING` / 「トレーニング」から起動。接続コードやポートを要求せず、GUI workerが既存TrainingモードをIPCへ渡す。英語／日本語切替に対応し、別セッション中は開始ボタンを無効化する。
- オフラインでは相手とのsyncCompleted通知が発生しないため、共有ランチャーのTraining起動はdllInitializedを確認してゲーム終了を待つよう修正。ネット対戦の同期待ちは維持。Trainingには既定D/Rを渡し、ネット対戦用INIの不正値でオフライン起動を妨げない。
- テスト用MBAACC_1からGUIを起動し、Trainingのキャラクター選択画面へ到達。IPCのtargetGameMode=1、30.5秒の起動維持を確認。以前の15秒同期タイムアウトで終了しない。トレーニング戦闘中の操作・機能の総合確認は未実施。
- 32bit GUI/CLIビルドと関連2テスト成功。根拠: `build_logs/gui_20260911/build_training.log`、`training_tests.log`、`training_real.log`、`training_worker.log`。既存ゲームDLLとテストDLLのSHA256は一致。ゲームDLL・入力時計・通信処理は変更なし。

ゲームの閉じるボタンで終了し、workerの終了・GUIの開始ボタン再有効化を確認。トレーニング画面の日本語切替も確認済み。
