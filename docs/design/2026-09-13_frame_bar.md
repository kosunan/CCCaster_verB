# トレーニング・観戦のフレームバー

## 実装

MBAACC Ver.1.07 Rev.1.4.0専用。モード1（トレーニング）と2（観戦）の戦闘HUDにP1/P2各45セルを表示する。初期表示ON、F1でON/OFF。操作案内はバー左上に統合し、非表示中も同じ位置に復帰方法を残す。目盛りと競合するLIVE/HOLD文字は表示しない。Ctrl+F3の既存HUD設定とは独立し、F4設定中は表示と切替を抑止する。対戦プレイヤーのモード0では採取も表示も行わない。F1は対象モードのWndProcと非同期キーバインド取得からゲームへ漏らさない。

| 表示 | 意味 |
| --- | --- |
| 暗い青灰 READY | 行動不能カウンタ0（全技のキャンセル可否を表すものではない） |
| 明るい緑 BUSY | 行動不能。発生前と後隙はここへまとめる |
| 赤 ACTIVE | 操作キャラのattackDataPtrが非0 |
| 青 GUARD | inBlockstunが非0 |
| 紫 HIT | 行動不能中の被弾動作。動作350はカウンタ0でも投げやられ |
| セル下端の緑線 | 攻撃判定等の色と独立した行動不能 |
| セル上端の白線 STOP | 当該キャラの停止、または共通画面停止 |

上段は45F分の毎F目盛り線を残し、定規の数字は1と5F刻みへ整理。その下のP1/P2各セルには同じ主状態の何F目かを通常フォント・影付きで記載し、主状態が変われば1へ戻す。リングから先頭が消えても連続カウントを保持し、100F以上も剰余で0へ戻さず全桁を幅内へ縮小する。停止の白線は主状態カウントをリセットしない。

1セルはゲームスレッドで採取したtrueFrameの1更新で、ヒットストップと画面停止も含む。ポーズ中は追加しない。描画回数・平均FPS・時計設定からフレームを補間しない。既存の有利不利計算は停止を除外するため、バーのセル数と意味が異なる。

状態セルを記録した後、双方READYのまま15F経過するとHOLDにして履歴を保持、次の動作で新規記録を開始する。45F超過では古いセルを捨てる。F1非表示でも採取を続ける。欠測・巻戻し・ラウンド変更・操作キャラ交代・モード変更・ゲーム外への遷移・トレーニング状態読込では履歴をリセットする。観戦の高速追いつきもゲーム更新ごとに採取し、中間Presentからは数えない。

ユーザー指定に従い、ADVはウィンドウ最上端y=0、フレームバーは旧ADVのy=82〜127（640×480基準）へ配置。横幅いっぱいを使い、公開済み30px版から高さを1.5倍の45pxへ拡大した。背景alpha=80/255、主な状態セルalpha=164/255、READYは104/255、空セルは72/255の半透明。文字は不透明・影付き、行動不能線は230/255、停止線は不透明にして見分けやすくする。P1は水色、P2はピンクの見出し。状態境界と最新セル端を強調する。観戦の名前・勝数は学習HUD表示中に既存の観戦帯へまとめて最上端ADVとの重なりを防ぐ。ゲームメモリ・保存対象・入力時計・通信形式は変更しない。

## 参照と判定の範囲

[kosunan/MBAACC_Training](https://github.com/kosunan/MBAACC_Training/tree/b9a74cb455c2da0ad8c601cffff2791e13b31af0)の`Fn_04_Cui_cnt.py`、`Fn_01_Address_Table_and_utill.py`、`Cf_02_state_num.py`を既存ローカルコピーから静的照合（HEAD一致）。攻撃判定の非0検査と被弾動作番号、80セル・30F保持を参考にC++で実装した。参照コードのポーリング・書込み・実行は取り込まない。

既存の版ガードと読取範囲検証の内側で、[ETMメモリ索引](../memory/etm_fields.md)と一致するActorData::pattern (+0xC)、inBlockstun (+0x177)、attackDataPtr (+0x320)を読む。P1攻撃データポインタの実アドレスは0x555454で、参照元のattack_statusと一致する。動的ポインタの参照先は読まない。

独立した飛び道具・非操作パートナーの攻撃判定はこの2行に含めない。SF6の技ごとの発生/持続/後隙の厳密分離、全キャラ・投げ・無敵・空中・特殊技の正確性は未確認。ACTIVEは接触成功や攻撃箱の幾何形状の判定ではなく、参照元と同じ攻撃データの存在を表す。
