# キャラセレHUDを共通化しD/Rを勝数の右隣へ移す

## 変更

キャラセレの名前・勝数が下部案内パネルのPushClipRectに巻き込まれ、画面上端に描画されない問題を修正。パネル生成前に共通ヘッダーを描く。プレイヤー名は左右、勝数は中央のまま、D/Rを勝数の右隣へ同じ背景・高さで配置する。名前は残り幅に収まるよう縮小し、長い右プレイヤー名とD/Rの重なりを防ぐ。

キャラセレ・通常対戦・観戦の初期HUDで同じ描画関数を使用する。キャラセレは次戦の設定値、対戦は適用済み値、観戦はホストから配信された値を使う。設定同期中や「次戦に適用」の通知でも値を表示する。

キャラセレと観戦の下端D/Rは撤去。対戦の下端はRTT・JIT・1F・必要時QPCだけとする。キャラセレのコントローラ設定案内・D/R変更キー案内・エラー通知は下部パネルへ残す。F1による観戦のADV／フレームバー切替は従来どおり、切替中は名前・勝数と一緒にD/Rも隠す。
