# 募集・参加と接続診断の視認性改善

## 変更

- 募集／参加を同じ大きさの中央配置ボタンに変更。選択中は背景に加えて明るい枠を表示。
- 本文フォントを17→19へ拡大。F4の設定案内は23の太字フォントで独立表示する。
- 上部を112→88pxへ圧縮し、重複する英語の誘い文句を撤去。ページ見出しを「ネット対戦」「接続診断」などの機能名にする。
- 画面を選択→操作説明／入力→開始→接続状態の順に整理。状態の見出しを太字で表示し、説明文の折返しから枠の高さを計算する。準備段階の起動失敗も強調表示する。
- 「接続できない？ 6秒で診断」を常時表示し、専用診断画面へ移動する。診断結果は見出し＋短い説明とし、失敗時は3項目の次の確認を表示。通信仕様の詳細を折りたたみに移し、STUN応答と相手との成功を区別する。
- 診断ではコード交換と相手テストの操作を状態に応じて表示。元の最大6秒／交換待機120秒を維持。対戦画面への戻る操作では実行中の診断を終了する。
- 詳細ログは暗い補助表示に変更し、結果や操作より強い紫色を抑える。

## 検証と成果物

- MinGW32 Releaseビルド成功、PE Machine `0x014C`。`build_logs/gui_readability_20260913/build.log`。
- Computer Useで検証用の `build/bin/CCCaster_v10_GUI.exe` を起動し、最小サイズの日本語・英語募集／参加画面、診断開始／STUN応答／コード入力／残り秒数／6秒失敗、ゲーム未配置時の長いエラー文を確認。既存GUIには操作しない。
- 公共STUN確認後、診断先にローカル無応答先 `127.0.0.1:9` を指定。相手とのWAN疎通を確認した扱いにはしない。
- 画像は同ディレクトリの `host_en.png`、`host_ja.png`、`join_en.png`、`join_ja.png`、`diagnostic_failed_ja.png`、`launch_error_ja.png`。診断失敗画像は最終F4拡大直前のビルドで、診断画面の処理は同一。コードや公開IPを含むSTUN結果画像は保存しない。
- `verification.json` にEXEのSHA256・32bit確認・対象画面・既存GUI保全を記録。診断エンジン `PunchDiagnostic.hpp` のSHA256は作業前後で一致。
- ゲームDLL・ネットコード・入力・時計には変更がないため、新規単体テストや実ゲーム対戦は実施しない。GUI実画面で今回の変更を検証する。
- 起動中のテストコピーのGUIは停止／上書きせず、検証用GUIのみ終了。ゲームフォルダーへの配布は行っていない。更新済みEXEは `build/bin/CCCaster_v10_GUI.exe`。

## 残る確認

別PC・別DPI・各回線の組合せ、診断成功後のWAN対戦への引継ぎは今回の確認対象外。診断結果が対戦・TCP観戦の成功保証ではない旨を維持する。
