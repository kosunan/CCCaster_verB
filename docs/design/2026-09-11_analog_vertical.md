# アナログ上下の修正（2026-09-11）

ユーザーの手操作でアナログ上下のみ反転を確認。旧CCCasterの `I:/work_space/CCCaster/OLD/lib/ControllerManager.cpp:182,188` と現行DirectInputHookを比較した。双方ともY/Ryを反転して上側を正へ正規化する。現行の設定UIが生成する軸バインドもこの規則を使用する。

原因は、補助入力の旧既定値がUp_Alt=A1-、Down_Alt=A1+となっていたこと。上=A1+、下=A1-へ修正した。軸の正規化や明示的に登録した主入力の符号規則は変更していない。

実機テストのXbox One設定はこの2項目だけを修正し、開始前のINIをbuild_logs/analog_vertical_fix_20260911へ保存した。他の方向・ボタン・トリガーの割り当てが不変であることを比較確認した。今後の未設定時の読み取り既定値と設定保存時の既定値も揃えた。

Releaseビルド成功。修正後の物理スティック操作はまだ確認していない。通信版7のまま。既存INIの明示値は読み取り既定値より優先されるため、配布には実機テスト用の修正済みXbox One設定も含める。別の独自設定では上下の補助値を個別に見直す必要がある。
