# ネット対戦の充実度と開発ロードマップ

更新: 2026-09-11。現在のコードと実行記録を照合。`[x]`は記載した範囲の実装・実行根拠あり、`[ ]`は未実装または完了条件未達。部分実装を項目全体の完了扱いにはしない。実機確認は特記がなければ同一PCの2窓、自動入力、対象MBAACC 1.07 Rev.1.4.0。

## L0 同期の正しさ

- [x] 予測・復元・再計算とRNG合流。`SceneRunner.cpp`、`PointerSnapshot.hpp`、`GameSnapshotLayout.hpp`、`RngState.hpp`。短い実対戦で確定フレーム一致。[現行の根拠](CURRENT_STATE.md)
- [ ] 決定論・セーブ／ロードの完全性保証。代表状態の一致は全メモリの保存漏れ検出ではない。全キャラ・全技・長時間は未達。
- [ ] 状態チェックサムの毎フレーム通信とプレイ中のデシンク検出。現在の`[STATE]`は診断ログのRNGハッシュ＋座標で、全状態チェックサムの通信ではない。
- [x] 試験後の自動ログ比較と不一致フレーム・項目・双方の値の保存。`compare_rollback_pair.py`。今回、判定器への故障注入テストを追加。
- [ ] 通常利用中の初回デシンクを起点とした、前後入力・全保存領域・ビルド情報の自動ダンプ。
- [ ] 入力リプレイの保存／再生と100%再現の常時試験。現在はリプレイ保存を意図的に無効化。ロールバック再計算と利用者向けリプレイを区別する。
