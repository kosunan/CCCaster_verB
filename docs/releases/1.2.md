# CCCaster verB 1.2

[Download cccaster_B.zip](https://github.com/kosunan/CCCaster_verB/releases/download/v1.2/cccaster_B.zip) — 起動停止・Training修正を含む通常配布版です。追加の診断版を探す必要はありません。

1.1の標準ZIPに修正が含まれず、対策入りのZIPを追加オプションのように掲載していたため、利用者が未対応版を取得していました。1.2では修正を通常配布へ統合し、最新版のダウンロード先を一本化します。

## 修正内容

- 起動時の多重起動判定をゲーム内の呼出箇所だけへ限定。WindowsのCreateMutexA／FindWindowA/Wを改変する旧処理による外部DLLへの干渉を解消。
- 通常CLIを含むTraining起動をP1開始へ統一。
- 起動完了・描画初期化のログと任意の入力診断を収録。通常利用に診断スクリプトは不要。
- キャラクターセレクト中のCPUスピンを短縮。Trainingにも専用の待機短縮を適用。
- GUIのタイトル、CLIの見出し、起動ログへ1.2を表示し、使用版を確認可能にする。

## 更新方法 / Installation

1. MBAAとCCCasterを終了し、既存のCLI・GUI・DLLをバックアップする。
2. `cccaster_B.zip` 内の `cccaster_B` から `CCCaster_v10.exe`、`CCCaster_v10_GUI.exe`、`libcccaster_hook.dll` の3点を、実際に使うゲームの既存 `cccaster_B` へまとめて上書きする。
3. `MBAA.exe`、INI、コントローラー設定は保持する。`cccaster_B/cccaster_B` の二重フォルダーを作らない。
4. 更新先の `CCCaster_v10_GUI.exe` を直接開く。タイトルと起動ログの `CCCaster verB 1.2` を確認する。対戦する双方を同じ配布版へ更新する。

Close MBAA and CCCaster, back up the three existing binaries, and replace all three files in your existing `cccaster_B` folder with those from this ZIP. Keep `MBAA.exe`, INI files, and controller profiles. Open the updated GUI directly and check that its title says **CCCaster verB 1.2**. Both players should update. The startup and Training fixes are already included; no optional diagnostic package is needed.

## 対象と確認範囲

MBAACC Ver.1.07 Rev.1.4.0（カニファン版）、Windows・32bit。通信版10／拡張6、D2/R4既定、高速起動とEXEのSHA-256照合を維持。Steam版・クロスプレイは対象外。

1.2最終バイナリで32bitビルド・37 CTest成功。GUIワーカー経由のTrainingでP1開始、初期化gate通知、描画デバイス生成、キャラ選択の描画・通常入力経路への到達を確認。実ゲーム内の観測DLLでもMutex・FindWindowの正常動作を確認した。

同一PC2窓、脚本入力、40秒、遅延15〜25ms／損失5%、短縮コード参加で1,331確定Fの入力・代表状態・保存領域比較は差分／欠落0。双方でロールバック10／5回、WASAPI activeを確認。根拠: `build_logs/release_1.2/`。物理操作・画面目視の試験とは区別する。

前回からのLinux CIにはWindows専用計測モジュールのimportに起因するPython解析テスト2件の失敗があり、今回のWindows製品修正とは別の残件として追跡する。

報告者PCの1.2での復旧、別PC・実回線・物理コントローラーの総合確認、全フレーム一定、高FPS報告の解決は未確認。通常配布への統合を、すべての残件の解消とは扱わない。

配布物は通常ZIP、同一コミットのソースZIP、SHA256一覧。ゲーム本体・個人設定・受領ログは収録しない。
